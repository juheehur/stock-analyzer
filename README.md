# 주식 데이터 분석기 (Stock Analyzer)

Streamlit을 사용한 주식 데이터 분석 웹 애플리케이션입니다.

## 주요 기능

### 📊 주가 차트 분석
- **선 차트**: 종가 기준 선형 차트
- **캔들스틱 차트**: 시가/고가/저가/종가를 캔들스틱으로 표시
- **거래량 분석**: 캔들스틱 차트 하단에 거래량 막대 그래프
- **이동평균선**: 20일, 60일 이동평균선 (표시/숨김 가능)
  - 20일 이동평균: 주황색 점선
  - 60일 이동평균: 초록색 점선

### 📈 종목 비교
- 여러 종목을 쉼표로 구분하여 입력
- 시작일 기준 수익률로 정규화하여 비교
- 같은 차트에 다른 색상으로 표시
- 비교 요약 테이블 제공

### 💰 수익률 계산기
- 매수 날짜와 금액 입력
- 현재 가치와 수익률(%) 자동 계산
- 수익/손실 색상 구분 표시

## 설치 방법

### 1. 저장소 클론
```bash
git clone https://github.com/your-username/stock_analyzer.git
cd stock_analyzer
```

### 2. 가상환경 생성 및 활성화
```bash
# macOS/Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### 3. 패키지 설치
```bash
pip install -r requirements.txt
```

## 실행 방법

```bash
streamlit run app.py
```

또는 가상환경의 Python을 직접 사용:

```bash
python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501`로 접속하면 앱을 사용할 수 있습니다.

## 사용 방법

### 주가 차트 조회
1. 종목 코드 입력 (예: `005930.KS`, `AAPL`)
2. 기간 선택 (1개월, 3개월, 6개월, 1년)
3. "데이터 조회" 버튼 클릭
4. 선 차트 또는 캔들스틱 탭에서 차트 확인
5. 이동평균선 체크박스로 표시/숨김 제어

### 종목 비교
1. "종목 비교" 섹션에서 종목 코드를 쉼표로 구분하여 입력
   - 예: `005930.KS, 000660.KS, AAPL`
2. 기간 선택
3. "종목 비교" 버튼 클릭
4. 시작일 기준 수익률로 정규화된 비교 차트 확인

### 수익률 계산
1. 왼쪽 사이드바의 "수익률 계산기" 사용
2. 종목 코드 입력
3. 매수 날짜 선택
4. 매수 금액 입력
5. "계산하기" 버튼 클릭
6. 현재 가치와 수익률 확인

## 종목 코드 형식

- 한국 주식: `005930.KS` (삼성전자), `000660.KS` (SK하이닉스)
- 미국 주식: `AAPL` (애플), `MSFT` (마이크로소프트), `GOOGL` (구글)

## 기술 스택

- **Streamlit**: 웹 애플리케이션 프레임워크
- **yfinance**: 주식 데이터 수집
- **Plotly**: 인터랙티브 차트 생성
- **Pandas**: 데이터 처리

## 요구사항

- Python 3.8 이상
- 패키지 목록은 `requirements.txt` 참조
